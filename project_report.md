# Отчёт по проекту: Автоматизация ML-пайплайна для предсказания качества вина

## Выбор темы и датасета

Тема проекта выбрана самостоятельно в рамках задания: автоматизировать ML-пайплайн на любом датасете.

**Выбранная тема:**

> Автоматизация ML-пайплайна для предсказания качества вина на основе химических характеристик.

**Датасет:**

> UCI Machine Learning Repository — Wine Quality Dataset (Дэкарвальо и ди-азеведо, 2009).

**Источник:**

> https://archive.ics.uci.edu/dataset/186/wine+quality

## Описание задачи

Проект решает задачу **бинарной классификации**: предсказывает, является ли вино «высококачественным» (оценка ≥ 7 по 10-балльной шкале) или «обычным» (оценка < 7).

Исходный датасет содержит **6 497 образцов** (красное и белое вино) с **12 признаками**:
- Химические свойства: кислотность, летучая кислотность, лимонная кислота, остаточный сахар, хлориды, диоксид серы, плотность, pH, сульфаты, алкоголь
- Метка: качество (0–10)
- Тип вина: красное (0) или белое (1)

## Реализованные компоненты пайплайна

### 1. Загрузка данных (`src/download_data.py`)
Автоматическое скачивание обоих датасетов (красное и белое вино) с UCI, объединение в один файл.

### 2. ETL и Feature Engineering (`src/etl.py`)
- Очистка: удаление дубликатов, обработка пропусков
- **Feature Engineering** — создание 9 новых признаков на основе предметной области:
  - `acid_ratio` — соотношение летучей и фиксированной кислотности
  - `so2_ratio` — соотношение свободного и общего диоксида серы
  - `salinity` — индикатор солёности
  - `alcohol_acid_ratio` — индикатор «тела» вина
  - `citric_presence`, `high_sulphates`, `high_sugar` — бинарные признаки

### 3. Обучение с автоматическим подбором гиперпараметров (`src/train.py`)
- **Optuna** с TPE-сэмплером для максимизации F1-score
- Сравнение 4 моделей: Logistic Regression, Random Forest, Extra Trees, Gradient Boosting
- Разделение: train / validation / test (стратифицированное)
- Сохранение лучшей модели в `models/best_model.joblib`

### 4. Оценка модели (`src/evaluate.py`)
- Метрики: accuracy, precision, recall, f1, roc_auc
- Отчёт в формате classification_report
- Сохранение в `reports/tables/evaluation_report.txt`

### 5. Инференс (`src/predict.py`)
- Предсказание для одиночного образца (dict) или DataFrame
- Поддержка возврата вероятностей
- Возможность загрузки из CSV

### 6. Тестирование (`tests/`)
- `test_etl.py` — 5 тестов: очистка, подготовка признаков, сплит, группы признаков
- `test_train.py` — тест инициализации пайплайна

### 7. Визуализация
- Confusion matrix
- ROC curve
- Bar chart метрик
- Распределение целевой переменной
- Importance признаков

### 8. Мониторинг (`src/monitor.py`)
- ResourceMonitor для отслеживания времени и памяти
- Декоратор `@monitor_resources`

### 9. Контейнеризация и CI
- Dockerfile
- docker-compose.yml с volume-маппингом для data, models, reports, mlruns
- Makefile с целями: install, download, train, evaluate, test, docker-build, docker-run

### 10. Экспериментальный трекинг
- MLflow интеграция (опционально)
- Логирование гиперпараметров, метрик, артефактов

## Финальные результаты

| Метрика | Значение |
|---------|----------|
| Accuracy | 0.843 |
| Precision | 0.583 |
| Recall | 0.609 |
| F1 Score | 0.596 |
| ROC AUC | 0.869 |

**Лучшая модель:** Random Forest
- n_estimators: 147
- max_depth: 21
- min_samples_split: 12
- min_samples_leaf: 4
- max_features: log2

**Использовано признаков:** 20 (11 оригинальных + 9 engineered)

## Почему эта тема подходит под задание

- Используется реальный открытый датасет из UCI Machine Learning Repository
- Задача относится к прикладной предметной области (анализ качества продуктов)
- Задача классификации с понятным целевым признаком
- Реализован полный ETL-пайплайн
- Автоматизирован подбор гиперпараметров через Optuna
- Добавлено feature engineering на основе предметной области
- Реализовано тестирование (pytest)
- Поддержка Docker и docker-compose
- Опциональная интеграция с MLflow для трекинга экспериментов
- Предусмотрен мониторинг ресурсов
